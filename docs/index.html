Method notes

  • Claude Opus 5.5 designed the tasks and graders and was not scored. Two contestants are Claude models.
  • Local output cap was 8,192 tokens including reasoning; cloud CLIs had 32K with continuation.
  • The two Flash-Next scores used different 3-bit files, so engine and quantisation effects are mixed.
  • One RTX 4090 with 64 GB RAM, Windows 11, llama.cpp b10929 / b11609 and Strata. Python, SQL and TypeScript/Vue only.
